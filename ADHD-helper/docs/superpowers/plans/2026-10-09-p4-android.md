# Phase 4: Compose UI module + Android App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Google-Tasks-like Compose Multiplatform UI in a new `ui/` module and the `androidApp/` module: screens, pairing, exact-alarm reminders with nag and notification actions, background sync, boot rescheduling, quick-add entry points, and a signed release APK with a version file.

**Architecture:** A new KMP module `ui/` (android + jvm targets, Compose MP, package `com.sagunkayastha.adhdhelper.ui`, depends on `:shared`) holds all screens, so the server jar (which depends on `:shared`) never pulls in Compose. Screen logic lives in plain state-holder classes (`ui/state/`, no AndroidX ViewModel) that wrap Phase 3's `TaskRepository`/`SyncClient` and expose `StateFlow`s; they are unit-tested on the JVM (`:ui:jvmTest`) against an in-memory SQLDelight DB. Composables only render state and call state-holder methods. The Android app builds one `AndroidContainer` in `AdhdApp` (DB, HTTP, settings, repository, sync, reminders) that the activity, receivers, workers, and tile reach through `applicationContext`; reminder planning is a pure function (`ReminderPlanner`) wrapped by an `AlarmManager` adapter (`ReminderScheduler`), tested with Robolectric.

**Tech Stack:** Kotlin 2.2.0, Compose Multiplatform 1.8.2 (Material 3), `sh.calvin.reorderable:reorderable` 2.4.3 (drag-to-reorder), Ktor client 3.2.0 (Phase 3's `createHttpClient()`; MockEngine in tests), SQLDelight 2.1.0, kotlinx-datetime 0.7.1, AndroidX activity-compose 1.10.1, core-ktx 1.16.0, work-runtime-ktx 2.10.2, lifecycle 2.9.1, Robolectric 4.14.1, JUnit 4.13.2, AGP 8.11.1, compileSdk/targetSdk 35, minSdk 29.

## Global Constraints

- **Docker-only:** every build and test runs in the build container; nothing on the host. Test command form (from the repo root `ADHD-helper/`):
  `docker run --rm --user "$(id -u):$(id -g)" -e GRADLE_USER_HOME=/gradle -v adhd-gradle:/gradle -v "$PWD":/src -w /src adhd-build gradle <task> --no-daemon`
  No emulator on the host: Android behaviour is tested with Robolectric only.
- Compose code lives only in `ui/` and the app modules; `shared/` gets no Compose dependency.
- Package root `com.sagunkayastha.adhdhelper`; applicationId `com.sagunkayastha.adhdhelper`; app name `ADHD Helper`.
- `minSdk = 29`, `targetSdk = 35`, `compileSdk = 35`.
- Wall-clock zone for due times: setting `zone`, default `America/Denver`. Always use `TimeZone.of(settings.zone)`; never the device zone.
- Contract names from the index are binding: `AppContainer`, `AppRoot(container: AppContainer)`, `TaskRepository`, `SyncClient`, `SyncState`, `AppSettings`, `EventsSocket`, `KtorSyncApi`, `SyncApi`, `Hlc`, `Ids`, `ReminderMath.nextFire`, `PairRequest`, `PairResponse`, `Health`, `Api.PREFIX`. Phase 3 names reused as-is: `createHttpClient()`, `createClientDatabase(driver)`, `DriverFactory(context)`, `AndroidAppSettings(context)`, `ClientJson`, `UnauthorizedException`; `ClientDatabase` is in `com.sagunkayastha.adhdhelper.client.db`.
- `Hlc` node id is `settings.deviceId` (generated locally on first run by Phase 3). `PairResponse.deviceId` is display-only and is not written into `settings.deviceId`.
- Pairing is `POST {serverUrl}/api/v1/pair` with `PairRequest(code, deviceName)`.
- Reminders: one exact alarm per open timed task via `AlarmManager.setExactAndAllowWhileIdle(RTC_WAKEUP, ...)`; `USE_EXACT_ALARM` plus `SCHEDULE_EXACT_ALARM` with `maxSdkVersion="32"`; inexact `setAndAllowWhileIdle` only when `canScheduleExactAlarms()` is false. Fire times up to 10 min in the past fire immediately (once); older are skipped.
- Notification channel id `reminders`, name `Reminders`, `IMPORTANCE_HIGH`; actions **Done**, **Snooze 10 min**, **Snooze 1 h** (Android shows at most three action buttons). **Tomorrow 9am** (= `snoozeUntil` 09:00 tomorrow in `settings.zone`; the due date is not changed) is not a notification action on Android; it is a "Snooze until tomorrow 9am" button on the shared task detail screen (Tasks 7, 12), and a notification action only on desktop (Phase 5). Nag: re-post every 10 min, up to 3 times, while `settings.nagEnabled`.
- Android sync: app start, 2 s after local edits (one-time, debounced), every 15 min (WorkManager, `NetworkType.CONNECTED`), on `EventsSocket` poke while the activity is started.
- The device token is never logged.
- Release keystore and its passwords live in the gitignored `keys/` dir at the repo root (never committed); nothing is written to `~`.
- If a pinned dependency version fails to resolve, use the nearest newer patch of the same minor and note it in the commit message.

## Review Focus

1. **Phone reboot across a DST switch:** after `BOOT_COMPLETED`, a daily 18:00 task is re-armed for 18:00 local on both sides of the March and November switch (index Review Focus 2). Pinned in Task 21.
2. **Reminder handled on the PC, then the phone syncs:** the phone's alarm is cancelled and any visible notification and pending nag for that task go away. Pinned in Task 18.
3. **Rescheduling right after an alarm fired** (an edit or sync within 10 min of the fire time): the reminder does not ring a second time. Pinned in Task 16 (planner) and Task 19 (receiver records the fire).
4. **Notification action tapped while the app process is dead:** Done/Snooze write through the repository, a sync is queued, and reminders are re-planned before the receiver finishes. Pinned in Task 20.
5. **Exact-alarm permission revoked (API 31–32) or notifications denied:** alarms are still set (inexact) and the UI shows a persistent banner. Pinned in Task 18 (fallback) and Task 3 (banner text).

### Assumptions about Phases 1–3 (read before Task 1)

- `gradle/libs.versions.toml` (Phase 1) has version keys `kotlin`, `agp`, `compose-multiplatform`, `ktor`, `sqldelight`, `kotlinx-coroutines`, `kotlinx-datetime`; camelCase plugin aliases `kotlinMultiplatform`, `kotlinJvm`, `kotlinSerialization`, `androidApplication`, `androidLibrary`, `composeMultiplatform`, `composeCompiler`, `sqldelight`, `ktor` (all declared `apply false` in the root `build.gradle.kts`); and library aliases `ktor-client-core`, `ktor-client-mock`, `ktor-client-content-negotiation`, `ktor-serialization-kotlinx-json`, `sqldelight-android-driver`, `sqldelight-sqlite-driver`, `kotlinx-datetime`, `kotlinx-coroutines-core`, `kotlinx-coroutines-test`. Never add a second key for the same artifact.
- Phase 3 signatures used here: `fun createHttpClient(): HttpClient` (ContentNegotiation with `ClientJson` and WebSockets installed), `fun createClientDatabase(driver: SqlDriver): ClientDatabase`, `class DriverFactory(context: Context) { fun createDriver(): SqlDriver }` (androidMain), `class AndroidAppSettings(context: Context) : AppSettings`, `val ClientJson: Json`, all in package `com.sagunkayastha.adhdhelper.client`. If a function name differs, use Phase 3's and change only the call site.
- `SyncState` is `com.sagunkayastha.adhdhelper.client.SyncState(online: Boolean, pending: Int, lastError: String?)`.
- When `KtorSyncApi` gets HTTP 401 it throws `UnauthorizedException`, and `SyncClient` reacts by setting `settings.token = null`; the UI shows the setup screen whenever `settings.token == null` (Task 3).
- `TaskRepository.move(id, beforeId, afterId)`: `beforeId` is the task that ends up directly above `id`, `afterId` the one directly below.
- `TaskRepository.tasks(listId)` emits non-deleted tasks ordered by `sortKey`, completed ones included (with `completedAt` set).

```kotlin
import io.ktor.http.contentType
import io.ktor.http.isSuccess
import kotlin.coroutines.cancellation.CancellationException

object Pairing {
    fun normalizeUrl(raw: String): String {
        val trimmed = raw.trim().trimEnd('/')
        return if (trimmed.startsWith("https://") || trimmed.startsWith("http://")) trimmed else "https://$trimmed"
    }

    fun normalizeCode(raw: String): String = raw.filter { !it.isWhitespace() && it != '-' }.uppercase()

    suspend fun pair(http: HttpClient, settings: AppSettings, url: String, code: String, deviceName: String): Result<Unit> {
        val base = normalizeUrl(url)
        val response = try {
            http.post("$base${Api.PREFIX}/pair") {
                contentType(ContentType.Application.Json)
                setBody(PairRequest(normalizeCode(code), deviceName))
            }
        } catch (e: CancellationException) {
            throw e
        } catch (e: ResponseException) {
            return Result.failure(IllegalStateException(statusMessage(e.response.status.value)))
        } catch (e: Exception) {
            return Result.failure(IllegalStateException("Cannot reach server: ${e.message}"))
        }
        if (!response.status.isSuccess()) {
            return Result.failure(IllegalStateException(statusMessage(response.status.value)))
        }
        val body = response.body<PairResponse>()
        settings.serverUrl = base
        settings.token = body.token
        settings.cursor = 0
        return Result.success(Unit)
    }

    private fun statusMessage(status: Int): String =
        if (status == 401 || status == 403 || status == 404) "Code invalid or expired" else "Server error $status"
}
```

```kotlin
package com.sagunkayastha.adhdhelper.ui.state

import com.sagunkayastha.adhdhelper.client.AppSettings
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow

sealed interface Screen {
    data object Setup : Screen
    data object Tasks : Screen
    data object Starred : Screen
    data object Assistant : Screen
    data class Detail(val listId: String, val taskId: String) : Screen
}

class RootState(private val settings: AppSettings) {
    private val _stack = MutableStateFlow(listOf(if (needsSetup()) Screen.Setup else Screen.Tasks))
    val stack: StateFlow<List<Screen>> = _stack
    val current: Screen get() = _stack.value.last()

    fun needsSetup(): Boolean = settings.serverUrl == null || settings.token == null

    /** Drawer destinations replace the whole stack. */
    fun showMain(screen: Screen) { _stack.value = listOf(screen) }

    fun open(screen: Screen) { _stack.value = _stack.value + screen }

    fun back(): Boolean {
        val stack = _stack.value
        if (stack.size > 1) {
            _stack.value = stack.dropLast(1)
            return true
        }
        if (current != Screen.Tasks && current != Screen.Setup) {
            showMain(Screen.Tasks)
            return true
        }
        return false
    }

    fun onPaired() = showMain(Screen.Tasks)

    /** Called whenever SyncClient.state changes; a revoked token clears settings.token. */
    fun checkAuth() {
        if (needsSetup() && current != Screen.Setup) _stack.value = listOf(Screen.Setup)
    }
}
```

```kotlin
package com.sagunkayastha.adhdhelper.ui.state

import com.sagunkayastha.adhdhelper.client.TaskRepository
import com.sagunkayastha.adhdhelper.model.TaskList
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.map
import kotlinx.coroutines.flow.stateIn

class ListsState(private val repo: TaskRepository, scope: CoroutineScope) {
    val lists: StateFlow<List<TaskList>> = repo.lists()
        .map { all -> all.filter { !it.deleted }.sortedBy { it.sortKey } }
        .stateIn(scope, SharingStarted.WhileSubscribed(5_000), emptyList())

    private val chosen = MutableStateFlow<String?>(null)

    val selectedListId: StateFlow<String?> = combine(lists, chosen) { all, id ->
        id?.takeIf { wanted -> all.any { it.id == wanted } } ?: all.firstOrNull()?.id
    }.stateIn(scope, SharingStarted.WhileSubscribed(5_000), null)

    fun select(id: String) { chosen.value = id }

    suspend fun create(title: String): TaskList? {
        val clean = title.trim()
        if (clean.isEmpty()) return null
        return repo.addList(clean).also { chosen.value = it.id }
    }

    suspend fun rename(id: String, title: String) {
        val clean = title.trim()
        if (clean.isNotEmpty()) repo.renameList(id, clean)
    }

    suspend fun delete(id: String) {
        repo.deleteList(id)
        if (chosen.value == id) chosen.value = null
    }
}
```

```kotlin
data class TaskRow(val task: Task, val subtasks: List<Task>)

data class TaskListUi(val open: List<TaskRow> = emptyList(), val completed: List<Task> = emptyList())

fun groupTasks(tasks: List<Task>): TaskListUi {
    val live = tasks.filter { !it.deleted }
    val openTasks = live.filter { it.completedAt == null }
    val openIds = openTasks.map { it.id }.toSet()
    val rows = openTasks
        .filter { it.parentId == null || it.parentId !in openIds }
        .map { top -> TaskRow(top, openTasks.filter { it.parentId == top.id }) }
    val completed = live.filter { it.completedAt != null }.sortedByDescending { it.completedAt }
    return TaskListUi(rows, completed)
}

object Reorder {
    /** (above, below) neighbours of the moved item once it sits at [to]. */
    fun neighbors(ids: List<String>, from: Int, to: Int): Pair<String?, String?> {
        val moved = ids.toMutableList()
        moved.add(to, moved.removeAt(from))
        return moved.getOrNull(to - 1) to moved.getOrNull(to + 1)
    }
}

class TaskListState(private val repo: TaskRepository, val listId: String, scope: CoroutineScope) {
    val ui: StateFlow<TaskListUi> = repo.tasks(listId)
        .map(::groupTasks)
        .stateIn(scope, SharingStarted.WhileSubscribed(5_000), TaskListUi())

    private val _completedExpanded = MutableStateFlow(false)
    val completedExpanded: StateFlow<Boolean> = _completedExpanded

    fun toggleCompletedExpanded() { _completedExpanded.value = !_completedExpanded.value }

    suspend fun toggleComplete(task: Task) =
        if (task.completedAt == null) repo.complete(task.id) else repo.uncomplete(task.id)

    suspend fun toggleStar(task: Task) = repo.updateTask(task.copy(starred = !task.starred))

    suspend fun moveOpen(from: Int, to: Int) {
        val ids = ui.value.open.map { it.task.id }
        if (from == to || from !in ids.indices || to !in ids.indices) return
        val (above, below) = Reorder.neighbors(ids, from, to)
        repo.move(ids[from], above, below)
    }
}

class StarredState(private val repo: TaskRepository, scope: CoroutineScope) {
    val tasks: StateFlow<List<Task>> = repo.starred()
        .map { all -> all.filter { !it.deleted && it.completedAt == null } }
        .stateIn(scope, SharingStarted.WhileSubscribed(5_000), emptyList())

    suspend fun toggleComplete(task: Task) =
        if (task.completedAt == null) repo.complete(task.id) else repo.uncomplete(task.id)

    suspend fun toggleStar(task: Task) = repo.updateTask(task.copy(starred = !task.starred))
}
```

```kotlin
data class AddTaskForm(
    val listId: String? = null,
    val title: String = "",
    val details: String = "",
    val date: LocalDate? = null,
    val time: LocalTime? = null,
    val repeat: RepeatRule? = null,
    val starred: Boolean = false,
)

class AddTaskState(
    private val repo: TaskRepository,
    private val zone: () -> TimeZone,
    private val clock: () -> Instant = { Clock.System.now() },
) {
    private val _form = MutableStateFlow(AddTaskForm())
    val form: StateFlow<AddTaskForm> = _form

    fun open(listId: String, prefill: String = "") { _form.value = AddTaskForm(listId = listId, title = prefill) }

    fun edit(change: (AddTaskForm) -> AddTaskForm) { _form.value = change(_form.value) }

    suspend fun submit(): Task? {
        val f = _form.value
        val listId = f.listId ?: return null
        val title = f.title.trim()
        if (title.isEmpty()) return null
        val date = f.date ?: if (f.time != null || f.repeat != null) clock().toLocalDateTime(zone()).date else null
        var task = repo.addTask(listId, title, dueDate = date, dueTime = f.time)
        if (f.details.isNotBlank() || f.repeat != null || f.starred) {
            task = task.copy(details = f.details.trim(), repeat = f.repeat, starred = f.starred)
            repo.updateTask(task)
        }
        _form.value = AddTaskForm(listId = listId)
        return task
    }
}

object RepeatText {
    fun describe(rule: RepeatRule): String {
        val n = rule.every
        val base = when (rule.freq) {
            Freq.DAILY -> if (n == 1) "Daily" else "Every $n days"
            Freq.WEEKLY -> if (n == 1) "Weekly" else "Every $n weeks"
            Freq.MONTHLY -> if (n == 1) "Monthly" else "Every $n months"
            Freq.YEARLY -> if (n == 1) "Yearly" else "Every $n years"
        }
        if (rule.freq != Freq.WEEKLY || rule.days.isEmpty()) return base
        return base + " on " + rule.days.sortedBy { it.ordinal }.joinToString(", ") { short(it) }
    }

    fun short(day: DayOfWeek): String = day.name.take(3).lowercase().replaceFirstChar { it.uppercase() }
}
```

```kotlin
import com.sagunkayastha.adhdhelper.client.TaskRepository
import com.sagunkayastha.adhdhelper.model.Task
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow

fun Task.withDue(date: LocalDate?, time: LocalTime?): Task = copy(
    dueDate = date,
    dueTime = if (date == null) null else time,
    snoozeUntil = null,
    repeat = if (date != dueDate) repeat?.copy(anchorDay = null) else repeat,
)

/** 09:00 on the next local day in [zone]. */
fun tomorrowNine(now: Instant, zone: TimeZone): Instant =
    now.toLocalDateTime(zone).date.plus(1, DateTimeUnit.DAY).atTime(LocalTime(9, 0)).toInstant(zone)

class TaskDetailState(
    private val repo: TaskRepository,
    val listId: String,
    val taskId: String,
    scope: CoroutineScope,
) {
    private val all = repo.tasks(listId)

    val task: StateFlow<Task?> = all
        .map { tasks -> tasks.find { it.id == taskId && !it.deleted } }
        .stateIn(scope, SharingStarted.WhileSubscribed(5_000), null)

    val subtasks: StateFlow<List<Task>> = all
        .map { tasks -> tasks.filter { it.parentId == taskId && !it.deleted } }
        .stateIn(scope, SharingStarted.WhileSubscribed(5_000), emptyList())

    private suspend fun load(): Task? = all.first().find { it.id == taskId && !it.deleted }

    suspend fun save(change: (Task) -> Task) {
        val current = load() ?: return
        val next = change(current)
        if (next != current) repo.updateTask(next)
    }

    suspend fun addSubtask(title: String): Task? {
        val current = load() ?: return null
        if (current.parentId != null) return null
        val clean = title.trim()
        if (clean.isEmpty()) return null
        return repo.addTask(listId, clean, parentId = taskId)
    }

    suspend fun toggleComplete(task: Task) =
        if (task.completedAt == null) repo.complete(task.id) else repo.uncomplete(task.id)

    suspend fun delete() = repo.deleteTask(taskId)

    /** In-app "Tomorrow 9am" snooze (Android notifications only fit Done / Snooze 10 min / Snooze 1 h). */
    suspend fun snoozeUntilTomorrow(now: Instant, zone: TimeZone) = repo.snooze(taskId, tomorrowNine(now, zone))
}
```

```kotlin
class SetupState(
    private val pair: suspend (String, String) -> Result<Unit>,
    private val sync: SyncClient,
    private val repo: TaskRepository,
) {
    val url = MutableStateFlow("https://tasks.sagunkayastha.com")
    val code = MutableStateFlow("")

    private val _busy = MutableStateFlow(false)
    val busy: StateFlow<Boolean> = _busy
    private val _error = MutableStateFlow<String?>(null)
    val error: StateFlow<String?> = _error

    suspend fun submit(): Boolean {
        val cleanCode = Pairing.normalizeCode(code.value)
        if (url.value.isBlank()) { _error.value = "Enter the server address"; return false }
        if (cleanCode.length != 8) { _error.value = "The pairing code has 8 characters"; return false }
        _error.value = null
        _busy.value = true
        try {
            val result = pair(url.value, cleanCode)
            if (result.isFailure) {
                _error.value = result.exceptionOrNull()?.message ?: "Pairing failed"
                return false
            }
            if (sync.syncOnce() && repo.lists().first().isEmpty()) repo.addList("My Tasks")
            return true
        } finally {
            _busy.value = false
        }
    }
```

```kotlin
    val reorder = rememberReorderableLazyListState(listState) { from, to ->
        val fromIdx = local.indexOfFirst { it.task.id == from.key }
        val toIdx = local.indexOfFirst { it.task.id == to.key }
```

```kotlin
    data object Create : ListDialog
    data class Rename(val list: TaskList) : ListDialog
    data class Delete(val list: TaskList) : ListDialog
}

@Composable
fun ListDialogs(dialog: ListDialog, lists: ListsState, onDone: () -> Unit) {
    val scope = rememberCoroutineScope()
    when (dialog) {
        ListDialog.Create -> TitleDialog("New list", "", onConfirm = { t -> scope.launch { lists.create(t); onDone() } }, onDismiss = onDone)
        is ListDialog.Rename -> TitleDialog("Rename list", dialog.list.title,
            onConfirm = { t -> scope.launch { lists.rename(dialog.list.id, t); onDone() } }, onDismiss = onDone)
        is ListDialog.Delete -> AlertDialog(
            onDismissRequest = onDone,
            title = { Text("Delete \"${dialog.list.title}\"?") },
            text = { Text("The list and all its tasks will be deleted.") },
            confirmButton = { TextButton(onClick = { scope.launch { lists.delete(dialog.list.id); onDone() } }) { Text("Delete") } },
            dismissButton = { TextButton(onClick = onDone) { Text("Cancel") } },
        )
    }
}

@Composable
private fun TitleDialog(heading: String, initial: String, onConfirm: (String) -> Unit, onDismiss: () -> Unit) {
    var text by remember { mutableStateOf(initial) }
    AlertDialog(
        onDismissRequest = onDismiss,
        title = { Text(heading) },
        text = { OutlinedTextField(text, { text = it }, singleLine = true, placeholder = { Text("List name") }) },
        confirmButton = { TextButton(enabled = text.isNotBlank(), onClick = { onConfirm(text) }) { Text("Done") } },
        dismissButton = { TextButton(onClick = onDismiss) { Text("Cancel") } },
    )
}

@Composable

    var open by remember { mutableStateOf(false) }
    Box {
        IconButton(onClick = { open = true }) { Icon(Icons.Filled.MoreVert, "List options") }
        DropdownMenu(expanded = open, onDismissRequest = { open = false }) {
            DropdownMenuItem(text = { Text("Rename list") }, onClick = { open = false; onRename() })
            DropdownMenuItem(text = { Text("Delete list") }, onClick = { open = false; onDelete() })
        }
    }
}
```

```kotlin
import android.content.Context
import androidx.work.Constraints
import androidx.work.ExistingPeriodicWorkPolicy
import androidx.work.ExistingWorkPolicy
import androidx.work.NetworkType
import androidx.work.OneTimeWorkRequestBuilder
import androidx.work.PeriodicWorkRequestBuilder
import androidx.work.WorkManager
import java.util.concurrent.TimeUnit

object SyncWork {
    const val PERIODIC = "sync-periodic"
    const val SOON = "sync-soon"

    private val network = Constraints.Builder().setRequiredNetworkType(NetworkType.CONNECTED).build()

    fun schedulePeriodic(context: Context) {
        WorkManager.getInstance(context).enqueueUniquePeriodicWork(
```

```kotlin
package com.sagunkayastha.adhdhelper.android.reminders

import com.sagunkayastha.adhdhelper.core.ReminderMath
import com.sagunkayastha.adhdhelper.model.Task
import kotlinx.datetime.TimeZone
import kotlin.time.Duration
import kotlin.time.Duration.Companion.minutes
import kotlin.time.Instant

data class AlarmPlan(
    val schedule: Map<String, Instant>,
    val fireNow: Map<String, Instant>,
    val cancel: Set<String>,
    val gone: Set<String>,
)

object ReminderPlanner {
    val LATE_WINDOW: Duration = 10.minutes

    fun plan(
        tasks: List<Task>,
        previouslyScheduled: Set<String>,
        firedAt: Map<String, Long>,
        zone: TimeZone,
        now: Instant,
    ): AlarmPlan {
        val schedule = mutableMapOf<String, Instant>()
        val fireNow = mutableMapOf<String, Instant>()
        for (task in tasks) {
            val fire = ReminderMath.nextFire(task, zone, now) ?: continue
            when {
                fire > now -> schedule[task.id] = fire
                now - fire <= LATE_WINDOW && firedAt[task.id] != fire.toEpochMilliseconds() -> fireNow[task.id] = fire
            }
        }
        val ids = tasks.map { it.id }.toSet()
        return AlarmPlan(
            schedule = schedule,
            fireNow = fireNow,
            cancel = previouslyScheduled - schedule.keys,
            gone = (previouslyScheduled + firedAt.keys) - ids,
        )
    }
}
```

```kotlin
package com.sagunkayastha.adhdhelper.android.reminders

import android.content.Context

class ReminderStore(context: Context) {
    private val prefs = context.getSharedPreferences("reminders", Context.MODE_PRIVATE)

    var scheduled: Set<String>
        get() = prefs.getStringSet(KEY_SCHEDULED, emptySet())!!.toSet()
        set(value) { prefs.edit().putStringSet(KEY_SCHEDULED, value).commit() }

    fun firedAt(): Map<String, Long> = prefs.all
        .filterKeys { it.startsWith(FIRED) }
        .mapNotNull { (k, v) -> (v as? Long)?.let { k.removePrefix(FIRED) to it } }
        .toMap()

    fun markFired(taskId: String, fireAtMillis: Long) { prefs.edit().putLong(FIRED + taskId, fireAtMillis).commit() }

    fun forget(taskId: String) { prefs.edit().remove(FIRED + taskId).commit() }

    private companion object {
        const val KEY_SCHEDULED = "scheduled"
        const val FIRED = "fired:"
    }
}
```

```kotlin
import android.app.AlarmManager
import android.app.PendingIntent
import android.content.Context
import android.content.Intent
import android.net.Uri

object ReminderIntents {
    private const val PREFIX = "com.sagunkayastha.adhdhelper.REMINDER_"
    const val ACTION_FIRE = PREFIX + "FIRE"
    const val ACTION_NAG = PREFIX + "NAG"
    const val ACTION_DONE = PREFIX + "DONE"
    const val ACTION_SNOOZE_10 = PREFIX + "SNOOZE_10"
    const val ACTION_SNOOZE_60 = PREFIX + "SNOOZE_60"

    const val EXTRA_TITLE = "title"
    const val EXTRA_FIRE_AT = "fireAt"
    const val EXTRA_ATTEMPT = "attempt"

    private const val FLAGS = PendingIntent.FLAG_IMMUTABLE or PendingIntent.FLAG_UPDATE_CURRENT

    fun taskUri(taskId: String): Uri = Uri.parse("adhd://task/$taskId")
    fun taskId(intent: Intent): String? = intent.data?.lastPathSegment
    fun notificationId(taskId: String): Int = taskId.hashCode()
    private fun requestCode(taskId: String): Int = taskId.hashCode()

    private fun base(context: Context, action: String, taskId: String): Intent =
        Intent(action).setPackage(context.packageName).setData(taskUri(taskId))

    fun alarm(context: Context, action: String, taskId: String, title: String, fireAtMillis: Long, attempt: Int): PendingIntent =
        PendingIntent.getBroadcast(
            context, requestCode(taskId),
            base(context, action, taskId)
                .putExtra(EXTRA_TITLE, title)
                .putExtra(EXTRA_FIRE_AT, fireAtMillis)
                .putExtra(EXTRA_ATTEMPT, attempt),
            FLAGS,
        )

    fun action(context: Context, action: String, taskId: String): PendingIntent =
        PendingIntent.getBroadcast(context, requestCode(taskId), base(context, action, taskId), FLAGS)

    fun cancelAlarm(context: Context, action: String, taskId: String) {
        val pi = PendingIntent.getBroadcast(
            context, requestCode(taskId), base(context, action, taskId),
            PendingIntent.FLAG_IMMUTABLE or PendingIntent.FLAG_NO_CREATE,
        ) ?: return
        context.getSystemService(AlarmManager::class.java).cancel(pi)
        pi.cancel()
    }
```

```kotlin
            ?.addFlags(Intent.FLAG_ACTIVITY_SINGLE_TOP)
        val open = launch?.let {
            PendingIntent.getActivity(context, ReminderIntents.notificationId(taskId), it,
                PendingIntent.FLAG_IMMUTABLE or PendingIntent.FLAG_UPDATE_CURRENT)
        }
        val text = if (attempt == 0) "Reminder" else "Still waiting (nudge $attempt of $MAX_NAGS)"
        val notification = NotificationCompat.Builder(context, CHANNEL_ID)
            .setSmallIcon(R.drawable.ic_notification)
            .setContentTitle(title)
            .setContentText(text)
            .setCategory(NotificationCompat.CATEGORY_REMINDER)
            .setPriority(NotificationCompat.PRIORITY_HIGH)
            .setContentIntent(open)
            .setAutoCancel(true)
            .addAction(0, "Done", ReminderIntents.action(context, ReminderIntents.ACTION_DONE, taskId))
            .addAction(0, "Snooze 10 min", ReminderIntents.action(context, ReminderIntents.ACTION_SNOOZE_10, taskId))
            .addAction(0, "Snooze 1 h", ReminderIntents.action(context, ReminderIntents.ACTION_SNOOZE_60, taskId))
            .build()
        val manager = NotificationManagerCompat.from(context)
        if (!manager.areNotificationsEnabled()) return
        try {
            manager.notify(ReminderIntents.notificationId(taskId), notification)
        } catch (_: SecurityException) {
            // POST_NOTIFICATIONS revoked between the check and the call; the banner (Task 22) tells the user.
        }
    }

    fun cancel(taskId: String) = NotificationManagerCompat.from(context).cancel(ReminderIntents.notificationId(taskId))
}
```

```kotlin
package com.sagunkayastha.adhdhelper.android.reminders

import android.app.AlarmManager
import android.app.PendingIntent
import android.content.Context
import android.os.Build
import com.sagunkayastha.adhdhelper.client.AppSettings
import com.sagunkayastha.adhdhelper.client.TaskRepository
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import kotlinx.datetime.TimeZone
import kotlin.time.Duration.Companion.minutes
import kotlin.time.Instant

class ReminderScheduler(
    private val context: Context,
    private val repo: TaskRepository,
    private val settings: AppSettings,
    private val store: ReminderStore,
    private val notifier: ReminderNotifier,
    private val clock: () -> Instant,
) {
    private val alarms = context.getSystemService(AlarmManager::class.java)
    private val mutex = Mutex()

    fun canExact(): Boolean = Build.VERSION.SDK_INT < Build.VERSION_CODES.S || alarms.canScheduleExactAlarms()

    suspend fun rescheduleAll() = mutex.withLock {
        val tasks = repo.openTimedTasks()
        val plan = ReminderPlanner.plan(tasks, store.scheduled, store.firedAt(), TimeZone.of(settings.zone), clock())
        val titles = tasks.associate { it.id to it.title }

        plan.cancel.forEach { ReminderIntents.cancelAlarm(context, ReminderIntents.ACTION_FIRE, it) }
        plan.gone.forEach {
            notifier.cancel(it)
            cancelNag(it)
            store.forget(it)
        }
        plan.schedule.forEach { (id, at) ->
            setAlarm(ReminderIntents.alarm(context, ReminderIntents.ACTION_FIRE, id, titles.getValue(id), at.toEpochMilliseconds(), 0), at)
        }
        plan.fireNow.forEach { (id, at) -> fire(id, titles.getValue(id), at.toEpochMilliseconds()) }
        store.scheduled = plan.schedule.keys
    }

    fun fire(taskId: String, title: String, fireAtMillis: Long) {
        notifier.post(taskId, title, attempt = 0)
        store.markFired(taskId, fireAtMillis)
        if (settings.nagEnabled) scheduleNag(taskId, title, attempt = 1)
    }

    fun scheduleNag(taskId: String, title: String, attempt: Int) {
        val at = clock() + 10.minutes
        setAlarm(ReminderIntents.alarm(context, ReminderIntents.ACTION_NAG, taskId, title, at.toEpochMilliseconds(), attempt), at)
    }

    fun cancelNag(taskId: String) = ReminderIntents.cancelAlarm(context, ReminderIntents.ACTION_NAG, taskId)

    private fun setAlarm(operation: PendingIntent, at: Instant) {
        val millis = at.toEpochMilliseconds()
        if (canExact()) alarms.setExactAndAllowWhileIdle(AlarmManager.RTC_WAKEUP, millis, operation)
        else alarms.setAndAllowWhileIdle(AlarmManager.RTC_WAKEUP, millis, operation)
    }
}
```

```kotlin
package com.sagunkayastha.adhdhelper.android.reminders

import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import com.sagunkayastha.adhdhelper.android.AdhdApp
import com.sagunkayastha.adhdhelper.android.AndroidContainer
import com.sagunkayastha.adhdhelper.core.ReminderMath
import kotlinx.coroutines.launch
import kotlinx.datetime.TimeZone
import kotlin.time.Duration.Companion.minutes

class AlarmReceiver : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        val container = (context.applicationContext as AdhdApp).container
        val pending = goAsync()
        container.scope.launch {
            try { handle(intent, container) } finally { pending.finish() }
        }
    }

    suspend fun handle(intent: Intent, c: AndroidContainer) {
        val id = ReminderIntents.taskId(intent) ?: return
        val task = c.repo.openTimedTasks().find { it.id == id } ?: return // done or deleted elsewhere
        val now = c.clock()
        val fireAt = ReminderMath.nextFire(task, TimeZone.of(c.settings.zone), now) ?: return
        if (fireAt > now + 1.minutes) return // moved later or snoozed: its own alarm will ring
        when (intent.action) {
            ReminderIntents.ACTION_FIRE -> c.reminders.fire(id, task.title, fireAt.toEpochMilliseconds())
            ReminderIntents.ACTION_NAG -> {
                val attempt = intent.getIntExtra(ReminderIntents.EXTRA_ATTEMPT, 1)
                c.notifier.post(id, task.title, attempt)
                if (c.settings.nagEnabled && attempt < ReminderNotifier.MAX_NAGS) c.reminders.scheduleNag(id, task.title, attempt + 1)
            }
        }
    }
}
```

```kotlin
import android.content.Context

class ActionReceiver : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        val container = (context.applicationContext as AdhdApp).container
        val pending = goAsync()
        container.scope.launch {
            try { handle(intent, container) } finally { pending.finish() }
        }
    }

    suspend fun handle(intent: Intent, c: AndroidContainer) {
        val id = ReminderIntents.taskId(intent) ?: return
        val now = c.clock()
        when (intent.action) {
            ReminderIntents.ACTION_DONE -> c.repo.complete(id)
            ReminderIntents.ACTION_SNOOZE_10 -> c.repo.snooze(id, now + 10.minutes)
            ReminderIntents.ACTION_SNOOZE_60 -> c.repo.snooze(id, now + 1.hours)
            else -> return
        }
        c.notifier.cancel(id)
        c.reminders.cancelNag(id)
        c.reminders.rescheduleAll()
        SyncWork.requestSoon(c.context)
    }
}
```

```kotlin
package com.sagunkayastha.adhdhelper.android

import android.app.DownloadManager
import android.content.Context
import android.net.Uri
import android.os.Environment
import com.sagunkayastha.adhdhelper.client.AppSettings
import com.sagunkayastha.adhdhelper.core.Health
import io.ktor.client.HttpClient
import io.ktor.client.call.body
import io.ktor.client.request.get
import io.ktor.http.isSuccess
import kotlin.coroutines.cancellation.CancellationException

class UpdateChecker(
    private val http: HttpClient,
    private val settings: AppSettings,
    private val currentVersion: Int,
) {
    suspend fun availableVersion(): Int? {
        val base = settings.serverUrl ?: return null
        val health = try {
            val response = http.get("$base/health")
            if (!response.status.isSuccess()) return null
            response.body<Health>()
        } catch (e: CancellationException) {
            throw e
        } catch (e: Exception) {
            return null
        }
        return health.apkVersion?.takeIf { it > currentVersion }
    }

    companion object {
        fun download(context: Context, settings: AppSettings) {
            val base = settings.serverUrl ?: return
            val token = settings.token ?: return
            val request = DownloadManager.Request(Uri.parse("$base/app/adhd-helper.apk"))
                .addRequestHeader("Authorization", "Bearer $token")
                .setMimeType("application/vnd.android.package-archive")
                .setTitle("ADHD Helper update")
                .setNotificationVisibility(DownloadManager.Request.VISIBILITY_VISIBLE_NOTIFY_COMPLETED)
                .setDestinationInExternalPublicDir(Environment.DIRECTORY_DOWNLOADS, "adhd-helper.apk")
            context.getSystemService(DownloadManager::class.java).enqueue(request)
        }
    }
}
```
