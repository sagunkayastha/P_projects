# Phase 7: Deploy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run `tasks-server` on archbox in `~/stacks/tasks`, reachable at `https://tasks.sagunkayastha.com` from the personal tailnet only, with the signed APK served from the server, the phone and this PC paired, and the end-to-end smoke test passed.

**Architecture:** The repo's committed source is rsynced from this PC to `archbox:~/stacks/tasks/src`. On archbox the build image `adhd-build` is built from `src/docker/build.Dockerfile` (Phase 1), then `~/stacks/tasks/docker-compose.yml` builds the server image from `src` with `docker/server.Dockerfile`, whose first stage is `FROM ${BUILD_IMAGE:-adhd-build}` (Phase 2). The container publishes `8020` on the LAN address only and joins the external `media_default` network, so the existing `media-caddy` (inside the `media-tailscale` personal-tailnet node, `100.96.124.103`) proxies `tasks.sagunkayastha.com` to `tasks-server:8020`. The phone gets its first APK over USB adb run from a throwaway container on this PC; later updates come from the token-protected `/app/adhd-helper.apk`.

**Tech Stack:** Docker 29.8.2 / Compose 5.1.4 on archbox, Caddy v2.11.4 (`media-caddy:cf`, Cloudflare DNS-01), Tailscale v1.102.3 sidecar (`media-tailscale`), rsync 3.x on both ends, `alpine:3.20` + `android-tools` (adb) in a throwaway container, build image `adhd-build` (Phase 1).

**Spec:** `docs/superpowers/specs/2026-10-09-adhd-helper-design.md` (section "Server, auth, deploy"); index `docs/superpowers/plans/2026-10-09-00-index.md`.

## Global Constraints

- **Docker-only:** every build, test, and tool runs inside a container. Nothing is installed on the host of either machine (no JDK, Gradle, Android SDK, Node, adb). Build command: `docker run --rm --user "$(id -u):$(id -g)" -e GRADLE_USER_HOME=/gradle -v adhd-gradle:/gradle -v "$PWD":/src -w /src adhd-build gradle <task> --no-daemon`
- **Never bind `0.0.0.0` on archbox.** The host's `tailscale0` is the employer tailnet. Publish only `192.168.0.162:8020`.
- **Secrets:** `CLAUDE_CODE_OAUTH_TOKEN` only in `~/stacks/tasks/.env` (0600) with placeholder `YOUR_TOKEN_HERE`; never committed, never logged, never printed by a verification command, never pasted into chat. Device tokens and pair codes are never written into the repo or STATE-LOG.md.
- **No files in `~`** on any host except the agreed `~/stacks/tasks/` on archbox (and the Caddyfile backup next to the existing ones). Staging on this PC goes in a `mktemp -d` directory.
- `rsync --delete` targets **only** `archbox.local:stacks/tasks/src/`, never another path.
- Never `docker compose down -v` and never `docker volume rm tasks-data`: that volume is the only copy of the server DB.
- Edit the Caddyfile **only** by appending with `>>` or restoring with `cp` (both keep the inode). `sed -i`, `mv`, or an editor that saves by rename gives the file a new inode and the running container keeps reading the old one.
- Time zone `America/Denver`. Package `com.sagunkayastha.adhdhelper`. App name `ADHD Helper`.
- Commits end with:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_0143tpSGVgH2wyDhkxyE99yr
  ```
- **STOP** steps are user actions. The executor halts, tells the user exactly what to do (and the file path, for secrets), and resumes only when the user says it is done.

## File Structure

| Path | Where | Responsibility |
|---|---|---|
| `deploy/sync-src.sh` | repo | Copies the committed tree to `archbox:~/stacks/tasks/src` (the image's build context). Refuses a dirty tree. The only place `--delete` is used. |
| `deploy/archbox/docker-compose.yml` | repo, copied to `~/stacks/tasks/docker-compose.yml` | The `tasks-server` service. Versioned here so changes are reviewed; archbox holds a copy. |
| `deploy/archbox/Caddyfile.tasks` | repo, appended to `~/stacks/media/caddy/Caddyfile` | The one site block for `tasks.sagunkayastha.com`. |
| `~/stacks/tasks/.env` | archbox only (0600) | `CLAUDE_CODE_OAUTH_TOKEN`. Never in the repo. |
| `~/stacks/tasks/src/` | archbox only | rsync target, build context. |
| `README.md` | repo | New "Deploy" section: first deploy, updates, rollback. |
| `STATE-LOG.md` | repo | Dated entry recording what was deployed. |

**Source transfer choice: rsync, not a git bundle.** One command, incremental, and nothing to maintain on archbox (no clone, no fetch/checkout). The bundle's one advantage, deploying exactly a commit, is kept by having `sync-src.sh` refuse a dirty working tree and print the commit it shipped, which goes into STATE-LOG.md. `.git/` stays on this PC.

**First APK install choice: adb over USB from a throwaway container on this PC** (`alpine:3.20` + `android-tools`, `--privileged` with `/dev/bus/usb`). It needs no server change, adds no unauthenticated download route, and installs nothing on the host. The rejected alternative, a pair-code-guarded unauthenticated LAN URL, would add a new public-to-the-LAN route and its tests to Phase 2's contract for a one-time event. After the first install, updates use the token-protected `/app/adhd-helper.apk` as the spec says.

- [ ] **Step 3: Write `deploy/sync-src.sh`**

```bash
#!/usr/bin/env bash
# Copy this checkout's committed source to archbox:~/stacks/tasks/src, the build context of
# ~/stacks/tasks/docker-compose.yml. --delete is scoped to that one directory. Build outputs,
# signing keys (keys/) and the desktop app image (dist/) never leave this PC.
#   deploy/sync-src.sh            ship it
#   DRY_RUN=1 deploy/sync-src.sh  list what would change, change nothing
set -euo pipefail
cd "$(dirname "$0")/.."
if [ -n "$(git status --porcelain)" ]; then
  echo "working tree not clean: commit first so the deploy matches a commit" >&2
  exit 1
fi
ssh archbox.local 'mkdir -p ~/stacks/tasks/src'
rsync -a --delete --itemize-changes ${DRY_RUN:+--dry-run} \
  --exclude='.git/' --exclude='build/' --exclude='.gradle/' --exclude='.kotlin/' \
  --exclude='.idea/' --exclude='keys/' --exclude='dist/' --exclude='local.properties' \
  --exclude='*.apk' --exclude='*.jks' --exclude='*.keystore' \
  ./ archbox.local:stacks/tasks/src/
git rev-parse --short HEAD
```

Run: `chmod +x deploy/sync-src.sh && bash -n deploy/sync-src.sh && echo ok`
Expected: `ok`
