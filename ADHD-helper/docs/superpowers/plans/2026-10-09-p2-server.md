# ADHD Helper Phase 2: Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Ktor JVM server (`server/`) that stores the synced rows in SQLite, pairs devices with one-time codes, serves `/api/v1/sync`, `/api/v1/events`, `/health` and the APK routes, purges old tombstones, takes nightly backups, has a `tasks` CLI, and ships as a Docker image.

**Architecture:** `ServerDb` wraps a SQLDelight JVM SQLite driver; each synced table stores the row's id, hlc, tombstone flag, server `rev`, server write time and the whole row as JSON (`body`), so the server never drops a field the shared models add. `SyncService` merges incoming rows with the shared `Merge.wins`, gives each winning row the next `rev`, and answers with every row above the client's cursor (or everything, flagged `fullResync`, when the cursor is behind the purge horizon or ahead of the server). Ktor routes are thin: bearer auth via `DeviceAuth`, JSON via kotlinx.serialization, a WebSocket that pushes `EventPoke` on every `EventBus.publish`.

**Tech Stack:** Kotlin 2.2.0 (JVM 21), Ktor 3.2.0 (server-netty, auth bearer, websockets, content-negotiation, test-host), SQLDelight 2.1.0 (`app.cash.sqldelight:sqlite-driver`), kotlinx-serialization 1.9.0, kotlinx-coroutines 1.10.2, Logback 1.5.18, Docker (`eclipse-temurin:21-jre-noble`, Node 22, pinned `@anthropic-ai/claude-code`).

**Spec:** `docs/superpowers/specs/2026-10-09-adhd-helper-design.md` (sections "Sync", "Server, auth, deploy", "Error handling", "Testing"); index `docs/superpowers/plans/2026-10-09-00-index.md` (Shared Interface Contract is binding).

## Review Focus

1. **A device offline longer than the 90-day tombstone window** syncs with a cursor below the purge horizon: it must get `fullResync = true` and every row the server holds, so a delete it never saw cannot come back. (Index item 5, purge part. Test: Task 3 `cursorBehindPurgeHorizonGetsFullResync`.)
2. **The server DB was restored from an older backup**, so a client's cursor is ahead of the server's rev: it must get `fullResync = true` instead of silently missing every row between the two revs. (Task 2 `cursorAheadOfServerMeansFullResync`.)
3. **One bad row in a sync batch** (blank id, malformed hlc, task without listId, or JSON that does not fit the model) must be returned in `rejected[]` while the rest of the batch applies, and the request still returns 200, so the client's outbox never gets stuck. (Task 2 `invalidRowsRejectedOthersApplied`, Task 5 `malformedRowIsRejectedNotFatal`.)
4. **A device whose clock runs ahead** sends an hlc an hour in the future: the server clock must move past it, so a later server-side write (assistant edit) still wins. (Task 2 `serverClockOvertakesFutureDeviceHlc`.)
5. **A revoked or unknown token, a reused or expired pair code**: every protected route (sync, events socket, both `/app/*` routes) answers 401, and a pair code works exactly once within 10 minutes. (Task 4 `DeviceAuthTest`, Task 5 `syncRequiresValidToken`, Task 6 `eventsRequireToken`, `appRoutesRequireToken`.)

**Decisions taken here (not fixed by the spec or contract):**

- Server rows are stored as JSON `body` plus the indexed columns the server itself needs (`id`, `hlc`, `deleted`, `rev`, `updated_at`). `updated_at` is the server's own clock at accept time; tombstone age is measured from it, never from the client hlc.
- **Rejected rows:** blank `id`; `hlc` not matching `^\d{15}-\d{5}-\S+$`; a `Task` with blank `listId`; any row whose JSON does not decode into the model. A task whose `listId` names a list the server has not seen is **accepted** (the list may arrive in a later batch; rejecting would make the client drop the user's task).
- **`fullResync`** is true when `cursor < purgeHorizon` or `cursor > rev before this request`. Then `changes` holds every row the server stores (live rows and not-yet-purged tombstones), `cursor` is the current rev, and the client must drop any synced local row that is not in the response (Phase 3).
- **Purge horizon** = highest `rev` among tombstones ever purged; a client whose cursor is at or above it has already seen every purged tombstone.
- **`/app/version`** returns the version as `text/plain` (e.g. `7`), 404 when `apk/version.txt` is missing or not an integer. `apk/version.txt` holds the integer `versionCode` only; the human `versionName` sits next to it in `apk/version-name.txt` (written by Phase 4's build, copied by Phase 7) and the server never reads it. `ApkStore.version()` reads the file on every call, so `/app/version` and `Health.apkVersion` change as soon as Phase 7 drops a new APK, without a restart. Failed pairing (unknown, used or expired code) returns **403**.
- **WebSocket:** after the socket subscribes, the server sends one `EventPoke(currentRev)` immediately, then one per `EventBus.publish`.
- Maintenance runs nightly at 03:30 in `ServerConfig.zone`: purge first, then backup.

```kotlin
package com.sagunkayastha.adhdhelper.server

import app.cash.sqldelight.db.QueryResult
import app.cash.sqldelight.driver.jdbc.sqlite.JdbcSqliteDriver
import com.sagunkayastha.adhdhelper.server.db.ServerDatabase
import java.util.Properties

internal object MetaKeys {
    const val REV = "rev"
    const val PURGE_HORIZON = "purge_horizon"
}

/**
 * The server's SQLite database. All access goes through [tx], which serialises writers inside
 * this process; WAL + busy_timeout let the `tasks` CLI (a second process) use the same file.
 */
class ServerDb(jdbcUrl: String) : AutoCloseable {
    private val driver = JdbcSqliteDriver(
        jdbcUrl,
        Properties().apply {
            setProperty("journal_mode", "WAL")
            setProperty("busy_timeout", "5000")
        },
    )
    private val lock = Any()
    internal val database: ServerDatabase

    init {
        if (userVersion() == 0L) {
            ServerDatabase.Schema.create(driver)
            driver.execute(null, "PRAGMA user_version = 1", 0)
        }
        database = ServerDatabase(driver)
    }

    internal fun <T> tx(block: ServerDatabase.() -> T): T =
        synchronized(lock) { database.transactionWithResult { database.block() } }

    /** Online copy of the whole DB to [path]. Must not run inside a transaction. */
    internal fun vacuumInto(path: String) {
        synchronized(lock) {
            driver.execute(null, "VACUUM INTO ?", 1) { bindString(0, path) }
        }
    }

    private fun userVersion(): Long =
        driver.executeQuery(
            null,
            "PRAGMA user_version",
            { cursor -> QueryResult.Value(if (cursor.next().value) cursor.getLong(0) ?: 0L else 0L) },
            0,
        ).value

    override fun close() = driver.close()
}
```

```kotlin
package com.sagunkayastha.adhdhelper.server

import com.sagunkayastha.adhdhelper.model.Task
import com.sagunkayastha.adhdhelper.model.Versioned

/**
 * Rows the server refuses (returned in SyncResponse.rejected). A task whose listId the server has
 * not seen is accepted on purpose: the list may come in a later batch.
 */
internal object RowRules {
    private val HLC = Regex("""^\d{15}-\d{5}-\S+$""")

    fun problem(row: Versioned): String? = when {
        row.id.isBlank() -> "blank id"
        !HLC.matches(row.hlc) -> "malformed hlc"
        row is Task && row.listId.isBlank() -> "task without listId"
        else -> null
    }
}
```

```kotlin
internal class Table<T : Versioned>(
    private val serializer: KSerializer<T>,
    private val isDeleted: (T) -> Boolean,
    private val selectBody: (String) -> String?,
    private val upsertRow: (id: String, hlc: String, deleted: Long, rev: Long, updatedAt: Long, body: String) -> Unit,
    private val selectSince: (Long) -> List<String>,
    private val selectLive: () -> List<String>,
) {
    fun get(id: String): T? = selectBody(id)?.let { decode(it) }

    fun put(row: T, rev: Long, nowMillis: Long) =
        upsertRow(row.id, row.hlc, if (isDeleted(row)) 1L else 0L, rev, nowMillis, ServerJson.encodeToString(serializer, row))

    fun since(cursor: Long): List<T> = selectSince(cursor).map { decode(it) }

    fun live(): List<T> = selectLive().map { decode(it) }

    private fun decode(body: String): T = ServerJson.decodeFromString(serializer, body)
}

internal class Tables(db: ServerDatabase) {
    private val q = db.rowsQueries

    val lists = Table(
        TaskList.serializer(), { it.deleted },
        { q.listBody(it).executeAsOneOrNull() },
        { id, hlc, deleted, rev, updatedAt, body -> q.upsertList(id, hlc, deleted, rev, updatedAt, body) },
        { q.listsSince(it).executeAsList() },
        { q.listsLive().executeAsList() },
    )
    val tasks = Table(
        Task.serializer(), { it.deleted },
        { q.taskBody(it).executeAsOneOrNull() },
        { id, hlc, deleted, rev, updatedAt, body -> q.upsertTask(id, hlc, deleted, rev, updatedAt, body) },
        { q.tasksSince(it).executeAsList() },
        { q.tasksLive().executeAsList() },
    )
    val notes = Table(
        Note.serializer(), { it.deleted },
        { q.noteBody(it).executeAsOneOrNull() },
        { id, hlc, deleted, rev, updatedAt, body -> q.upsertNote(id, hlc, deleted, rev, updatedAt, body) },
        { q.notesSince(it).executeAsList() },
        { q.notesLive().executeAsList() },
    )
    val messages = Table(
        ChatMessage.serializer(), { false },
        { q.messageBody(it).executeAsOneOrNull() },
        { id, hlc, deleted, rev, updatedAt, body -> q.upsertMessage(id, hlc, deleted, rev, updatedAt, body) },
        { q.messagesSince(it).executeAsList() },
        { q.messagesLive().executeAsList() },
    )

    fun since(cursor: Long): Changes = Changes(
        lists = lists.since(cursor), tasks = tasks.since(cursor),
        notes = notes.since(cursor), messages = messages.since(cursor),
    )

    fun live(): Changes = Changes(
        lists = lists.live(), tasks = tasks.live(), notes = notes.live(), messages = messages.live(),
```

```kotlin
package com.sagunkayastha.adhdhelper.server

import com.sagunkayastha.adhdhelper.model.Versioned
import com.sagunkayastha.adhdhelper.server.db.ServerDatabase
import com.sagunkayastha.adhdhelper.sync.Changes
import com.sagunkayastha.adhdhelper.sync.Hlc
import com.sagunkayastha.adhdhelper.sync.Merge
import com.sagunkayastha.adhdhelper.sync.SyncRequest
import com.sagunkayastha.adhdhelper.sync.SyncResponse

class SyncService(
    private val db: ServerDb,
    private val hlc: Hlc,
    private val events: EventBus,
    private val nowMillis: () -> Long = System::currentTimeMillis,
) {
    private val hlcLock = Any()

    fun currentRev(): Long = db.tx { metaQueries.getMeta(MetaKeys.REV).executeAsOne() }

    /** Thread-safe server hlc stamp for server-side writers (Phase 6 tools). */
    fun stamp(): String = synchronized(hlcLock) { hlc.now() }

    fun apply(req: SyncRequest): SyncResponse {
        val rejected = mutableListOf<String>()
        var changed = false
        val response = db.tx {
            val tables = Tables(this)
            val revBefore = metaQueries.getMeta(MetaKeys.REV).executeAsOne()
            val revAfter = merge(tables, req.changes, revBefore, rejected)
            changed = revAfter != revBefore
            val horizon = metaQueries.getMeta(MetaKeys.PURGE_HORIZON).executeAsOne()
            val full = req.cursor < horizon || req.cursor > revBefore
            SyncResponse(
                cursor = revAfter,
                changes = tables.since(if (full) 0L else req.cursor),
                rejected = rejected.toList(),
                fullResync = full,
            )
        }
        if (changed) events.publish(response.cursor)
        return response
    }

    /** Server-side write (assistant tools). Rows must already carry an hlc from [stamp]. */
    fun write(changes: Changes): Long {
        val all: List<Versioned> = changes.lists + changes.tasks + changes.notes + changes.messages
        all.forEach { row -> RowRules.problem(row)?.let { throw IllegalArgumentException("row '${row.id}': $it") } }
        var changed = false
        val rev = db.tx {
            val before = metaQueries.getMeta(MetaKeys.REV).executeAsOne()
            merge(Tables(this), changes, before, mutableListOf()).also { changed = it != before }
        }
        if (changed) events.publish(rev)
        return rev
    }

    fun snapshot(): Changes = db.tx { Tables(this).live() }

    private fun ServerDatabase.merge(t: Tables, changes: Changes, revStart: Long, rejected: MutableList<String>): Long {
        var rev = revStart
        val now = nowMillis()
        fun <T : Versioned> mergeRows(table: Table<T>, rows: List<T>) {
            for (row in rows) {
                if (RowRules.problem(row) != null) {
                    rejected += row.id
                    continue
                }
                synchronized(hlcLock) { hlc.observe(row.hlc) }
                if (!Merge.wins(row, table.get(row.id))) continue
                rev += 1
                table.put(row, rev, now)
            }
        }
        mergeRows(t.lists, changes.lists)
        mergeRows(t.tasks, changes.tasks)
        mergeRows(t.notes, changes.notes)
        mergeRows(t.messages, changes.messages)
        if (rev != revStart) metaQueries.setMeta(rev, MetaKeys.REV)
        return rev
    }
}
```

```kotlin
package com.sagunkayastha.adhdhelper.server

import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Job
import kotlinx.coroutines.delay
import kotlinx.coroutines.isActive
import kotlinx.coroutines.launch
import org.slf4j.LoggerFactory
import java.nio.file.Files
import java.nio.file.Path
import java.nio.file.StandardCopyOption
import java.time.Duration
import java.time.Instant
import java.time.ZoneId

class Maintenance(
    private val db: ServerDb,
    private val dataDir: Path,
    private val zone: ZoneId,
    private val nowMillis: () -> Long = System::currentTimeMillis,
) {
    /** Deletes tombstones older than 90 days and raises the purge horizon. Returns rows removed. */
    fun purgeTombstones(): Int = db.tx {
        val cutoff = nowMillis() - TOMBSTONE_TTL_MS
        val q = rowsQueries
        val count = q.countPurgeableLists(cutoff).executeAsOne() +
            q.countPurgeableTasks(cutoff).executeAsOne() +
            q.countPurgeableNotes(cutoff).executeAsOne()
        if (count > 0) {
            val maxRev = maxOf(
                q.maxPurgeableListRev(cutoff).executeAsOne(),
                q.maxPurgeableTaskRev(cutoff).executeAsOne(),
                q.maxPurgeableNoteRev(cutoff).executeAsOne(),
            )
            q.purgeLists(cutoff)
            q.purgeTasks(cutoff)
            q.purgeNotes(cutoff)
            val old = metaQueries.getMeta(MetaKeys.PURGE_HORIZON).executeAsOne()
            metaQueries.setMeta(maxOf(old, maxRev), MetaKeys.PURGE_HORIZON)
        }
        count.toInt()
    }

    /** VACUUM INTO backups/tasks-YYYY-MM-DD.db (date in [zone]); keeps the newest [KEEP_BACKUPS]. */
    fun backup(): Path {
        val dir = Files.createDirectories(dataDir.resolve("backups"))
        val date = Instant.ofEpochMilli(nowMillis()).atZone(zone).toLocalDate()
        val target = dir.resolve("tasks-$date.db")
        val tmp = dir.resolve("tasks-$date.db.tmp")
        Files.deleteIfExists(tmp)
        db.vacuumInto(tmp.toString())
        Files.move(tmp, target, StandardCopyOption.REPLACE_EXISTING, StandardCopyOption.ATOMIC_MOVE)
        Files.list(dir).use { s -> s.filter { BACKUP_NAME.matches(it.fileName.toString()) }.toList() }
            .sortedDescending()
            .drop(KEEP_BACKUPS)
            .forEach { Files.delete(it) }
        return target
    }

    companion object {
        const val TOMBSTONE_TTL_MS = 90L * 24 * 60 * 60 * 1000
        const val KEEP_BACKUPS = 14
        private val BACKUP_NAME = Regex("""^tasks-\d{4}-\d{2}-\d{2}\.db$""")
    }
}

/** Milliseconds from [nowMillis] to the next [hour]:[minute] wall-clock time in [zone]. */
fun millisUntilNext(hour: Int, minute: Int, nowMillis: Long, zone: ZoneId): Long {
    val now = Instant.ofEpochMilli(nowMillis).atZone(zone)
    var next = now.toLocalDate().atTime(hour, minute).atZone(zone)
    if (!next.isAfter(now)) next = now.toLocalDate().plusDays(1).atTime(hour, minute).atZone(zone)
    return Duration.between(now, next).toMillis()
}

/** Nightly at 03:30 local: purge tombstones, then back up. Runs until the scope is cancelled. */
fun CoroutineScope.launchMaintenance(m: Maintenance, zone: ZoneId): Job = launch {
    val log = LoggerFactory.getLogger("maintenance")
    while (isActive) {
        delay(millisUntilNext(3, 30, System.currentTimeMillis(), zone))
        runCatching { m.purgeTombstones() }
            .onSuccess { log.info("purged {} tombstones", it) }
            .onFailure { log.warn("tombstone purge failed", it) }
        runCatching { m.backup() }
            .onSuccess { log.info("backup written to {}", it) }
            .onFailure { log.warn("backup failed", it) }
    }
}
```

```kotlin
package com.sagunkayastha.adhdhelper.server

import com.sagunkayastha.adhdhelper.core.PairRequest
import com.sagunkayastha.adhdhelper.core.PairResponse
import com.sagunkayastha.adhdhelper.sync.Ids
import java.security.MessageDigest
import java.security.SecureRandom
import java.util.Base64

/** One-time pair codes and long-lived device tokens. Only SHA-256 hashes of tokens are stored. */
class DeviceAuth(
    private val db: ServerDb,
    private val nowMillis: () -> Long = System::currentTimeMillis,
    private val random: SecureRandom = SecureRandom(),
) {
    fun newPairCode(): String {
        val code = String(CharArray(CODE_LENGTH) { ALPHABET[random.nextInt(ALPHABET.length)] })
        db.tx {
            val now = nowMillis()
            authQueries.deleteExpiredPairCodes(now)
            authQueries.insertPairCode(code, now + CODE_TTL_MS)
        }
        return code
    }

    fun pair(req: PairRequest): PairResponse? {
        val code = req.code.uppercase().filter { it in ALPHABET }
        val token = ByteArray(32).also { random.nextBytes(it) }
            .let { Base64.getUrlEncoder().withoutPadding().encodeToString(it) }
        val deviceId = Ids.newId()
        val name = req.deviceName.trim().take(64).ifBlank { "device" }
        val paired = db.tx {
            val now = nowMillis()
            authQueries.deleteExpiredPairCodes(now)
            if (authQueries.validPairCode(code, now).executeAsOneOrNull() == null) return@tx false
            authQueries.deletePairCode(code)
            authQueries.insertDevice(deviceId, name, sha256Hex(token), now)
            true
        }
        return if (paired) PairResponse(token = token, deviceId = deviceId) else null
    }

    fun verify(token: String): String? {
        if (token.isBlank()) return null
        return db.tx { authQueries.deviceIdForHash(sha256Hex(token)).executeAsOneOrNull() }
    }

    fun list(): List<Pair<String, String>> =
        db.tx { authQueries.activeDevices { id, name -> id to name }.executeAsList() }

    fun revoke(deviceId: String): Boolean = db.tx {
        if (authQueries.activeDevice(deviceId).executeAsOneOrNull() == null) return@tx false
        authQueries.revokeDevice(deviceId)
        true
    }

    companion object {
        /** No 0/O, 1/I/L: easy to read off a terminal and type on a phone. */
        const val ALPHABET = "ABCDEFGHJKMNPQRSTUVWXYZ23456789"
        const val CODE_LENGTH = 8
        const val CODE_TTL_MS = 600_000L

        fun sha256Hex(s: String): String =
            MessageDigest.getInstance("SHA-256").digest(s.toByteArray()).joinToString("") { "%02x".format(it) }
    }
}
```

```kotlin
/**
 * The sideloaded APK and its versionCode, dropped into dataDir/apk/ by the deploy (Phase 7).
 * version.txt = integer versionCode only (versionName lives in version-name.txt, unused here).
 * Read on every call, so a new APK is picked up without a restart.

class ApkStore(dataDir: Path) {
    private val dir = dataDir.resolve("apk")

    fun version(): Int? {
        val file = dir.resolve("version.txt")
        if (!Files.isRegularFile(file)) return null
        return Files.readString(file).trim().toIntOrNull()
    }

    fun apk(): File? = dir.resolve(APK_NAME).toFile().takeIf { it.isFile }

    companion object {
        const val APK_NAME = "adhd-helper.apk"
```

```kotlin
import com.sagunkayastha.adhdhelper.model.ChatMessage

import io.ktor.server.plugins.BadRequestException
import kotlinx.serialization.KSerializer
import kotlinx.serialization.json.JsonArray
import kotlinx.serialization.json.JsonElement
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.JsonPrimitive
import kotlinx.serialization.json.contentOrNull
import kotlinx.serialization.json.longOrNull

/**
 * Decodes a sync body row by row, so one row that does not fit the model is reported in
 * `rejected` instead of failing the whole request (spec: sync is never stuck).
 */
internal object LenientSync {
    fun decode(body: String): Pair<SyncRequest, List<String>> {
        val root = runCatching { ServerJson.parseToJsonElement(body) }.getOrNull() as? JsonObject
            ?: throw BadRequestException("sync body is not a JSON object")
        val cursor = (root["cursor"] as? JsonPrimitive)?.longOrNull
            ?: throw BadRequestException("sync body has no numeric cursor")
        val changes = root["changes"] as? JsonObject ?: JsonObject(emptyMap())
        val rejected = mutableListOf<String>()

        fun <T> rows(key: String, serializer: KSerializer<T>): List<T> =
            ((changes[key] as? JsonArray) ?: emptyList<JsonElement>()).mapNotNull { element ->
                runCatching { ServerJson.decodeFromJsonElement(serializer, element) }.getOrElse {
                    rejected += ((element as? JsonObject)?.get("id") as? JsonPrimitive)?.contentOrNull ?: ""
                    null
                }
            }

        val request = SyncRequest(
            cursor = cursor,
            changes = Changes(
                lists = rows("lists", TaskList.serializer()),
                tasks = rows("tasks", Task.serializer()),
                notes = rows("notes", Note.serializer()),
                messages = rows("messages", ChatMessage.serializer()),
            ),
        )
        return request to rejected
    }
}
```

```kotlin
internal fun Route.eventRoutes(deps: ServerDeps) {

            deps.events.revs

                .collect { rev -> send(Frame.Text(ServerJson.encodeToString(EventPoke.serializer(), EventPoke(rev)))) }
        }
        try {
            for (frame in incoming) {
                // Clients send nothing; drain until the socket closes.
            }
        } finally {
            pusher.cancel()
        }
    }
```

```kotlin
object Cli {
    private const val USAGE = "usage: tasks [serve | pair | devices | revoke <device-id>]"

    fun run(args: List<String>, env: Map<String, String>, out: PrintStream): Int {
        val config = ServerConfig(
            dataDir = env["TASKS_DATA_DIR"] ?: "/data",
            port = env["TASKS_PORT"]?.toIntOrNull() ?: 8020,
            zone = env["TASKS_ZONE"] ?: "America/Denver",
        )
        return when (args.firstOrNull() ?: "serve") {
            "serve" -> {
                serve(config)
                0
            }
            "pair" -> openServerDb(config).use { db ->
                out.println(DeviceAuth(db).newPairCode())
                out.println("Valid for 10 minutes, single use.")
                0
            }
            "devices" -> openServerDb(config).use { db ->
                val devices = DeviceAuth(db).list()
                if (devices.isEmpty()) out.println("no devices")
                devices.forEach { (id, name) -> out.println("$id\t$name") }
                0
            }
            "revoke" -> {
                val id = args.getOrNull(1) ?: return usage(out)
                openServerDb(config).use { db ->
                    if (DeviceAuth(db).revoke(id)) {
                        out.println("revoked $id")
                        0
                    } else {
                        out.println("no active device $id")
                        1
                    }
                }
            }
            else -> usage(out)
        }
    }

    private fun usage(out: PrintStream): Int {
        out.println(USAGE)
        return 2
    }
}

fun openServerDb(config: ServerConfig): ServerDb {
    val dir = Files.createDirectories(Path.of(config.dataDir))
    return ServerDb("jdbc:sqlite:${dir.resolve("tasks.db")}")
}

fun serve(config: ServerConfig) {
    val db = openServerDb(config)
    val events = EventBus()
    val sync = SyncService(db, Hlc("server", System::currentTimeMillis), events)
    val deps = ServerDeps(config, db, sync, events, DeviceAuth(db))
    val zone = ZoneId.of(config.zone)
    CoroutineScope(SupervisorJob() + Dispatchers.IO)
        .launchMaintenance(Maintenance(db, Path.of(config.dataDir), zone), zone)
    // 0.0.0.0 is inside the container only. The host-side publish address is set by compose
    // (127.0.0.1 locally, 192.168.0.162 on archbox) and is never 0.0.0.0.
    embeddedServer(Netty, port = config.port, host = "0.0.0.0") { module(deps) }.start(wait = true)
}
```

```dockerfile
# syntax=docker/dockerfile:1.7
# Server image. Build context = repo root:
#   docker build -f docker/server.Dockerfile -t adhd-tasks-server .
# Stage 1 builds from source in the project's build image (Phase 1: docker build -t adhd-build -f docker/build.Dockerfile docker),
# so no host-side build/ directory is needed.
ARG BUILD_IMAGE=adhd-build

FROM ${BUILD_IMAGE:-adhd-build} AS build
WORKDIR /src
COPY . .
# adhd-build sets HOME=/tmp; keep the Gradle cache in a BuildKit cache mount at /gradle.
RUN --mount=type=cache,target=/gradle GRADLE_USER_HOME=/gradle gradle :server:buildFatJar --no-daemon -q

FROM node:22.18.0-bookworm-slim AS node

FROM eclipse-temurin:21-jre-noble
ARG CLAUDE_CODE_VERSION=2.0.14

RUN apt-get update \
 && apt-get install -y --no-install-recommends curl ca-certificates \
 && rm -rf /var/lib/apt/lists/*

# Node 22 + npm from the official image, then the pinned claude CLI (used by Phase 6's chat runner).
COPY --from=node /usr/local/bin/node /usr/local/bin/node
COPY --from=node /usr/local/lib/node_modules/npm /usr/local/lib/node_modules/npm
RUN ln -s /usr/local/lib/node_modules/npm/bin/npm-cli.js /usr/local/bin/npm \
 && npm install -g "@anthropic-ai/claude-code@${CLAUDE_CODE_VERSION}" \
 && npm cache clean --force \
 && claude --version

RUN useradd --system --uid 10001 --create-home --home-dir /home/tasks --shell /usr/sbin/nologin tasks \
 && mkdir -p /app /data \
 && chown tasks:tasks /data

COPY --from=build /src/server/build/libs/tasks-server.jar /app/tasks-server.jar
COPY --chmod=0755 docker/tasks /usr/local/bin/tasks

ENV TASKS_DATA_DIR=/data \
    TASKS_PORT=8020 \
    TASKS_ZONE=America/Denver \
    TZ=America/Denver \
    HOME=/home/tasks

USER tasks
VOLUME /data
EXPOSE 8020
HEALTHCHECK --interval=30s --timeout=5s --start-period=30s --retries=3 \
  CMD curl -fsS http://127.0.0.1:8020/health || exit 1
ENTRYPOINT ["tasks"]
CMD ["serve"]
```

Replace `2.0.14` with the version chosen in Step 1.
