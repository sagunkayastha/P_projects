# Phase 5: Desktop App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native Linux desktop app (Compose Multiplatform, JVM) that shows the shared `AppRoot` UI, lives in the system tray, syncs with the server, and fires reminders through `notify-send` with Done / Snooze / Tomorrow actions, packaged as a self-contained jpackage app image in the repo's `dist/` folder.

**Architecture:** A new `desktopApp/` Gradle module (Kotlin JVM + Compose desktop) depends on `:ui` (Phase 4's shared Compose screens, which `api`-depend on `:shared`). It reuses Phase 3's `FileAppSettings` (0600 settings file), `DriverFactory`, `createClientDatabase`, `createHttpClient()` and Phase 4's `Pairing.pair` instead of re-implementing them. Small, unit-tested classes do the desktop-only work: `DesktopPaths` (XDG dirs), `PrivateFiles`/`privateSettings` (0700 dirs around Phase 3's settings file), `InstanceLock`, `DesktopSync` (start / debounced edits / 5 min / socket poke), `DesktopReminders` (30 s polling loop with fired set and nag), `NotifySendNotifier` (with `TrayNotifier` fallback). `DesktopApp` wires them like the Android app does, and `Main.kt` hosts the window and tray. `createDistributable` runs in the build container; the app image is copied into `dist/adhd-helper/` and run from there.

**Tech Stack:** Kotlin 2.2.0, Compose Multiplatform 1.8.2 (desktop), Ktor client 3.2.0 (CIO, WebSockets, ContentNegotiation; MockEngine in tests), SQLDelight 2.1.0 `sqlite-driver`, kotlinx-coroutines 1.10.2 (+ `-test`), kotlinx-datetime 0.7.1, JDK 21 jpackage (inside `adhd-build`).

**Spec:** `docs/superpowers/specs/2026-10-09-adhd-helper-design.md` (sections "Decisions made by default: Desktop app", "Reminders: Desktop", "Server, auth, deploy: Pairing, Desktop install"). Index: `docs/superpowers/plans/2026-10-09-00-index.md` (Shared Interface Contract is binding).

## Review Focus

1. **App closed or PC asleep at fire time:** on next start a reminder missed by up to 12 h fires once; older ones do not fire (no flood of stale alerts on every launch). Pinned in Task 6 (`missedWithinWindowFiresOnFirstTick`, `staleMissedReminderDoesNotFire`).
2. **Snooze in a polling loop:** the loop must fire at the snooze time once and not re-fire the old due time after the snooze has passed. `ReminderMath.nextFire` (Phase 1) returns the snooze whenever it is later than the due instant, independent of `now`, so the loop uses it directly as the fire key. Pinned in Task 6 (`snoozeFiresAtSnoozeTimeOnceThenStops`).
3. **Handled on the phone while the PC is nagging:** after the next sync the task is completed/snoozed, so the PC nag stops. Pinned in Task 6 (`handledElsewhereStopsNag`).
4. **`notify-send` missing, too old (no `--action`), or a title starting with `-`:** the app falls back to tray notifications and never crashes; titles are passed after `--` so they are never parsed as options. Pinned in Task 7 (`missingBinaryFallsBackAndStays`, `nonZeroExitFallsBack`, `dashTitleStaysPositional`).
5. **Two instances (autostart plus a manual launch):** the second exits at once, so reminders never ring twice on the PC. Pinned in Task 2 (`secondAcquireFailsUntilReleased`).

```kotlin
package com.sagunkayastha.adhdhelper.desktop

import java.nio.file.Path

/** Per-user app dirs following the XDG base-dir spec (relative or blank values are ignored). */
class DesktopPaths(env: Map<String, String>, home: String) {
    val configDir: Path = xdg(env["XDG_CONFIG_HOME"], Path.of(home, ".config")).resolve(APP_DIR)
    val dataDir: Path = xdg(env["XDG_DATA_HOME"], Path.of(home, ".local", "share")).resolve(APP_DIR)
    val settingsFile: Path get() = configDir.resolve("settings.properties")
    val dbFile: Path get() = dataDir.resolve("tasks.db")
    val lockFile: Path get() = dataDir.resolve("app.lock")

    companion object {
        const val APP_DIR = "adhd-helper"

        fun fromSystem(): DesktopPaths = DesktopPaths(System.getenv(), System.getProperty("user.home"))

        private fun xdg(value: String?, fallback: Path): Path =
            value?.takeIf { it.isNotBlank() }?.let { Path.of(it) }?.takeIf { it.isAbsolute } ?: fallback
    }
}
```

```kotlin
package com.sagunkayastha.adhdhelper.desktop

import com.sagunkayastha.adhdhelper.client.FileAppSettings
import java.nio.file.Files
import java.nio.file.Path
import java.nio.file.attribute.PosixFilePermissions

object PrivateFiles {
    val DIR_PERMS = PosixFilePermissions.fromString("rwx------")
    val FILE_PERMS = PosixFilePermissions.fromString("rw-------")

    /** Creates the dir (and missing parents) with mode 0700 if it does not exist. */
    fun ensureDir(dir: Path) {
        if (!Files.isDirectory(dir)) {
            Files.createDirectories(dir, PosixFilePermissions.asFileAttribute(DIR_PERMS))
        }
    }

    /** Sets mode 0600 on an existing file. */
    fun restrict(file: Path) {
        if (Files.exists(file)) Files.setPosixFilePermissions(file, FILE_PERMS)
    }
}

/** Phase 3's FileAppSettings (atomic 0600 writes) inside a 0700 dir; tightens a file someone loosened. */
fun privateSettings(file: Path): FileAppSettings {
    PrivateFiles.ensureDir(file.parent)
    PrivateFiles.restrict(file)
    return FileAppSettings(file)
}
```

`InstanceLock.kt`:

```kotlin
package com.sagunkayastha.adhdhelper.desktop

import java.nio.channels.FileChannel
import java.nio.channels.FileLock
import java.nio.channels.OverlappingFileLockException
import java.nio.file.Path
import java.nio.file.StandardOpenOption

/** Holds an exclusive lock on a file so only one app instance runs. */
class InstanceLock private constructor(
    private val channel: FileChannel,
    private val lock: FileLock,
) : AutoCloseable {
    override fun close() {
        lock.release()
        channel.close()
    }

    companion object {
        fun tryAcquire(file: Path): InstanceLock? {
            PrivateFiles.ensureDir(file.parent)
            val channel = FileChannel.open(file, StandardOpenOption.CREATE, StandardOpenOption.WRITE)
            val lock = try {
                channel.tryLock()
            } catch (e: OverlappingFileLockException) {
                null // already held inside this JVM
            }
            if (lock == null) {
                channel.close()
                return null
            }
            return InstanceLock(channel, lock)
        }
    }
}
```

```kotlin
class DesktopSync(
    private val scope: CoroutineScope,
    private val syncOnce: suspend () -> Boolean,
    private val debounce: Duration = 2.seconds,
    private val period: Duration = 5.minutes,
) {
    private val requests = MutableSharedFlow<Unit>(extraBufferCapacity = 1, onBufferOverflow = BufferOverflow.DROP_OLDEST)
    private val mutex = Mutex()

    fun start(): Job = scope.launch {
        launch { requests.debounce(debounce).collect { syncNow() } }
        while (isActive) {
            syncNow()
            delay(period)
        }
    }

    fun requestSync() {
        requests.tryEmit(Unit)
    }

    suspend fun syncNow(): Boolean = mutex.withLock {
        try {
            syncOnce()
        } catch (e: CancellationException) {
            throw e
        } catch (e: Exception) {
            false // offline is normal; SyncClient.state carries the error for the UI
        }
    }
}
```

```kotlin
package com.sagunkayastha.adhdhelper.desktop

import com.sagunkayastha.adhdhelper.core.ReminderMath
import com.sagunkayastha.adhdhelper.model.Task
import kotlinx.coroutines.CancellationException
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Job
import kotlinx.coroutines.delay
import kotlinx.coroutines.isActive
import kotlinx.coroutines.launch
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import kotlinx.datetime.TimeZone
import kotlin.time.Duration.Companion.hours
import kotlin.time.Duration.Companion.minutes
import kotlin.time.Duration.Companion.seconds
import kotlin.time.Instant

/** Fires due reminders while the desktop app runs. */
class DesktopReminders(
    private val scope: CoroutineScope,
    private val openTimedTasks: suspend () -> List<Task>,
    private val zone: () -> TimeZone,
    private val nagEnabled: () -> Boolean,
    private val now: () -> Instant,
    private val notifier: Notifier,
    private val onAction: suspend (Task, ReminderAction) -> Unit,
) {
    private data class Key(val taskId: String, val fireAt: Instant)

    private class Alert(
        var shows: Int,
        var lastShownAt: Instant,
        var showing: Boolean = true,
        var handled: Boolean = false,
    )

    private val mutex = Mutex()
    private val fired = mutableSetOf<Key>()
    private val alerts = mutableMapOf<Key, Alert>()

    fun start(): Job = scope.launch {
        while (isActive) {
            try {
                tick()
            } catch (e: CancellationException) {
                throw e
            } catch (e: Exception) {
                System.err.println("reminders: tick failed: ${e.message}")
            }
            delay(TICK)
        }
    }

    suspend fun tick() {
        val t = now()
        val tz = zone()
        val pending: Map<Key, Task> = openTimedTasks()
            .mapNotNull { task -> ReminderMath.nextFire(task, tz, t)?.let { Key(task.id, it) to task } }
            .toMap()
        val toShow = mutableListOf<Pair<Key, Task>>()
        mutex.withLock {
            alerts.keys.retainAll(pending.keys) // completed/snoozed/rescheduled/deleted = handled
            fired.removeAll { t - it.fireAt > MISSED_WINDOW }
            for ((key, task) in pending) {
                if (key.fireAt > t) continue
                if (key !in fired) {
                    if (t - key.fireAt > MISSED_WINDOW) continue
                    fired += key
                    alerts[key] = Alert(shows = 1, lastShownAt = t)
                    toShow += key to task
                } else {
                    val alert = alerts[key] ?: continue
                    if (nagEnabled() && !alert.handled && !alert.showing &&
                        alert.shows <= MAX_NAGS && t - alert.lastShownAt >= NAG_INTERVAL
                    ) {
                        alert.shows++
                        alert.lastShownAt = t
                        alert.showing = true
                        toShow += key to task
                    }
                }
            }
        }
        toShow.forEach { (key, task) -> show(key, task) }
    }

    private fun show(key: Key, task: Task) {
        scope.launch {
            val action = try {
                notifier.show(task)
            } catch (e: CancellationException) {
                throw e
            } catch (e: Exception) {
                System.err.println("reminders: notify failed: ${e.message}")
                null
            }
            mutex.withLock {
                alerts[key]?.let {
                    it.showing = false
                    it.lastShownAt = now()
                    if (action != null) it.handled = true
                }
            }
            if (action != null) {
                try {
                    onAction(task, action)
                } catch (e: CancellationException) {
                    throw e
                } catch (e: Exception) {
                    System.err.println("reminders: action ${action.key} failed: ${e.message}")
                }
            }
        }
    }

    companion object {
        val TICK = 30.seconds
        val NAG_INTERVAL = 10.minutes
        const val MAX_NAGS = 3
        val MISSED_WINDOW = 12.hours
    }
}
```

```kotlin
package com.sagunkayastha.adhdhelper.desktop

import com.sagunkayastha.adhdhelper.model.Task
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import java.io.IOException

data class ProcessResult(val exitCode: Int, val stdout: String)

/** Runs a command and waits for it; throws IOException if the program cannot start. */
fun interface ProcessRunner {
    fun run(command: List<String>): ProcessResult
}

object SystemProcessRunner : ProcessRunner {
    override fun run(command: List<String>): ProcessResult {
        val process = ProcessBuilder(command)
            .redirectError(ProcessBuilder.Redirect.DISCARD)
            .start()
        process.outputStream.close()
        val out = process.inputStream.bufferedReader().readText()
        return ProcessResult(process.waitFor(), out)
    }
}

/**
 * Shows a critical notification with action buttons via `notify-send --wait` and returns the
 * chosen action. Switches to [fallback] for good if notify-send is missing or fails.
 */
class NotifySendNotifier(
    private val runner: ProcessRunner,
    private val fallback: Notifier,
) : Notifier {
    @Volatile private var useFallback = false

    override suspend fun show(task: Task): ReminderAction? {
        if (useFallback) return fallback.show(task)
        val result = try {
            withContext(Dispatchers.IO) { runner.run(command(task)) }
        } catch (e: IOException) {
            useFallback = true
            return fallback.show(task)
        }
        if (result.exitCode != 0) {
            useFallback = true
            return fallback.show(task)
        }
        return parseAction(result.stdout)
    }

    companion object {
        fun command(task: Task): List<String> =
            listOf("notify-send", "--app-name=ADHD Helper", "--urgency=critical") +
                ReminderAction.entries.map { "--action=${it.key}=${it.label}" } +
                listOf("--wait", "--", title(task), body(task))

        fun title(task: Task): String = task.title.ifBlank { "Reminder" }

        fun body(task: Task): String = buildString {
            task.dueTime?.let { append("Due ").append(it.toString()) }
            if (task.details.isNotBlank()) {
                if (isNotEmpty()) append(" · ")
                append(task.details)
            }
        }

        fun parseAction(stdout: String): ReminderAction? =
            stdout.lineSequence().map { it.trim() }.lastOrNull { it.isNotEmpty() }
                ?.let { ReminderAction.fromKey(it) }
    }
}
```

```kotlin
import androidx.compose.ui.window.TrayState
import app.cash.sqldelight.db.SqlDriver
import com.sagunkayastha.adhdhelper.client.AppSettings
import com.sagunkayastha.adhdhelper.client.DriverFactory
import com.sagunkayastha.adhdhelper.client.EventsSocket
import com.sagunkayastha.adhdhelper.client.KtorSyncApi
import com.sagunkayastha.adhdhelper.client.SyncClient
import com.sagunkayastha.adhdhelper.client.TaskRepository
import com.sagunkayastha.adhdhelper.client.createClientDatabase
import com.sagunkayastha.adhdhelper.client.createHttpClient
import com.sagunkayastha.adhdhelper.sync.Hlc
import com.sagunkayastha.adhdhelper.ui.AppContainer
import com.sagunkayastha.adhdhelper.ui.Pairing
import io.ktor.client.HttpClient
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.SupervisorJob
import kotlinx.coroutines.cancel
import kotlinx.coroutines.launch
import kotlinx.datetime.TimeZone
import kotlin.time.Clock

const val DEVICE_NAME = "Linux desktop"

/** Wires the desktop app the same way as Android: one repo, one sync client, one container. */
class DesktopApp private constructor(
    val container: AppContainer,
    val tray: TrayState,
    private val settings: AppSettings,
    private val scope: CoroutineScope,
    private val http: HttpClient,
    private val driver: SqlDriver,
    private val desktopSync: DesktopSync,
    private val reminders: DesktopReminders,
    private val socket: EventsSocket,
) {
    fun start() {
        desktopSync.start()
        reminders.start()
        if (settings.token != null) socket.start(scope)
    }

    fun shutdown() {
        socket.stop()
        scope.cancel()
        http.close()
        driver.close()
    }

    companion object {
        fun create(
            paths: DesktopPaths,
            notifierFor: (TrayState) -> Notifier = { NotifySendNotifier(SystemProcessRunner, TrayNotifier(it)) },
        ): DesktopApp {
            PrivateFiles.ensureDir(paths.configDir)
            PrivateFiles.ensureDir(paths.dataDir)
            val settings = privateSettings(paths.settingsFile)

            val driver = DriverFactory(paths.dbFile.toString()).createDriver()
            PrivateFiles.restrict(paths.dbFile)
            val db = createClientDatabase(driver)

            // deviceId is generated locally on first run and is the HLC node id; pairing never changes it.
            val hlc = Hlc(settings.deviceId) { System.currentTimeMillis() }
            var onLocalChange: () -> Unit = {}
            val repo = TaskRepository(db, hlc) { onLocalChange() }

            val http = createHttpClient()
            val syncClient = SyncClient(KtorSyncApi(http, settings), repo, settings)
            val scope = CoroutineScope(SupervisorJob() + Dispatchers.Default)
            val desktopSync = DesktopSync(scope, { if (settings.token == null) false else syncClient.syncOnce() })
            onLocalChange = { desktopSync.requestSync() }
            val socket = EventsSocket(http, settings) { desktopSync.syncNow() }

            val tray = TrayState()
            val now = { Clock.System.now() }
            val zone = { TimeZone.of(settings.zone) }
            val handler = ReminderActionHandler(
                complete = { repo.complete(it) },
                snooze = { id, until -> repo.snooze(id, until) },
                now = now,
                zone = zone,
            )
            val reminders = DesktopReminders(
                scope = scope,
                openTimedTasks = { repo.openTimedTasks() },
                zone = zone,
                nagEnabled = { settings.nagEnabled },
                now = now,
                notifier = notifierFor(tray),
                onAction = handler::handle,
            )

            val container = AppContainer(
                repo = repo,
                sync = syncClient,
                settings = settings,
                chat = null, // Phase 6 wires ChatClient here
                pair = { url, code ->
                    val result = Pairing.pair(http, settings, url, code, DEVICE_NAME)
                    if (result.isSuccess) {
                        scope.launch { desktopSync.syncNow() }
                        socket.stop()
                        socket.start(scope)
                    }
                    result
                },
            )
            return DesktopApp(container, tray, settings, scope, http, driver, desktopSync, reminders, socket)
        }
    }
}
```

```kotlin
import kotlin.system.exitProcess

/** Simple drawn icon so the app needs no binary image resources. */
object TrayIcon : Painter() {
    override val intrinsicSize = Size(64f, 64f)
    override fun DrawScope.onDraw() {
        drawCircle(color = Color(0xFF1A73E8))
        drawCircle(color = Color.White, radius = size.minDimension * 0.18f)
    }
}

fun main(args: Array<String>) {
    val cli = parseCli(args)
    if (cli.version) {
        println(versionText())
        return
    }
    val paths = DesktopPaths.fromSystem()
    val lock = InstanceLock.tryAcquire(paths.lockFile)
    if (lock == null) {
        System.err.println("ADHD Helper is already running.")
        exitProcess(1)
    }
    val app = DesktopApp.create(paths)
    app.start()

    application {
        var windowVisible by remember { mutableStateOf(!(cli.minimized && isTraySupported)) }
        val quit = {
            app.shutdown()
            lock.close()
            exitApplication()
        }
        if (isTraySupported) {
            Tray(
                state = app.tray,
                icon = TrayIcon,
                tooltip = "ADHD Helper",
                onAction = { windowVisible = true },
                menu = {
                    Item("Open", onClick = { windowVisible = true })
                    // Phase 4's QuickAdd: AppRoot opens the add-task sheet when a request is pending.
                    Item("New task", onClick = { windowVisible = true; QuickAdd.request() })
                    Item("Quit", onClick = quit)
                },
            )
        }
        Window(
            // Close hides to tray; without a tray, closing must quit or the app is unreachable.
            onCloseRequest = { if (isTraySupported) windowVisible = false else quit() },
            visible = windowVisible,
            title = "ADHD Helper",
            icon = TrayIcon,
            state = rememberWindowState(width = 420.dp, height = 760.dp),
        ) {
            AppRoot(app.container)
        }
    }
}
```
